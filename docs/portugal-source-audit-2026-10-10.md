# Portugal agency-source audit — 10 October 2026

The Portuguese [open-data listing for ProCiv open incidents](https://dados.gov.pt/en/datasets/prociv-ocorrencias-em-aberto) is published by ANEPC. It describes current civil-protection incidents from the SADO operations system and labels the dataset CC BY 4.0. Its metadata was last updated on 24 June 2021 and lists no downloadable resource URL.

The [current ANEPC occurrences page](https://prociv.gov.pt/pt/ocorrencias/) links to an [official ArcGIS experience](https://prociv-portal.geomai.mai.gov.pt/arcgis/apps/experiencebuilder/experience/?id=29e83f11f7a34339b35364e483e3846f). A read of that experience's public configuration on 10 October 2026 found a notice saying the incident dashboard was temporarily unavailable; the notice itself says it was updated on 23 January 2026. The configuration does not establish whether the notice is currently visible to visitors. It references embedded dashboards but does not expose a confirmed current event layer with stable incident identity and update time.

**Decision:** Keep Portugal as a source candidate. Do not add an adapter until an official machine-readable event endpoint, wildfire category, stable ID, update time, live response, and reuse terms for that actual endpoint are verified. The old portal licence label alone does not prove the current embedded dashboard can be republished.
